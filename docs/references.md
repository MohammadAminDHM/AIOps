# منابع رسمی پیشنهادی

برای به‌روز نگه داشتن مسیر آموزشی، هنگام اجرای واقعی labها از منابع رسمی زیر استفاده کنید.

| موضوع | منبع |
| --- | --- |
| RunPod Pods | https://docs.runpod.io/pods/overview |
| RunPod Serverless Endpoints | https://docs.runpod.io/serverless/endpoints/overview |
| RunPod Serverless Storage | https://docs.runpod.io/serverless/storage/overview |
| RunPod Network Volumes | https://docs.runpod.io/storage/network-volumes |
| RunPod SSH اتصال به Pod | https://docs.runpod.io/pods/configuration/use-ssh |
| RunPod CLI / runpodctl | https://docs.runpod.io/runpodctl/overview |
| RunPod REST API | https://docs.runpod.io/api-reference/overview |
| Docker GPU access | https://docs.docker.com/engine/containers/gpu/ |
| vLLM OpenAI-compatible Server | https://docs.vllm.ai/en/stable/serving/openai_compatible_server/ |
| vLLM Production Metrics | https://docs.vllm.ai/en/stable/serving/metrics.html |

## نکته استفاده از منابع

قبل از اجرای labهای وابسته به RunPod، Docker GPU یا vLLM، نسخه‌های مستندات رسمی را دوباره بررسی کنید؛ چون endpoint settings، CLI flags، CUDA image tags و runtime options ممکن است تغییر کنند.
