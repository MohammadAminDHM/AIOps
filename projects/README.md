# Projects

این پوشه محل قرار دادن پروژه‌های تمرینی و پروژه نهایی نیروهاست.

This folder is the workspace for learner projects and final submissions.

Suggested structure:

```text
projects/
└── learner-name-or-team-name/
    ├── README.md
    ├── app/
    ├── Dockerfile
    ├── runpod/
    ├── benchmarks/
    ├── cost-report.md
    └── incident-runbook.md
```

Copy `sections/09-final-project-template/` as a starting point.
